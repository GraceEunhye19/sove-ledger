Sovereign Ledger
Sovereign Ledger is a Personal Finance Tracker that contains Budget Allocations, a Transaction Ledger, Spending tracking insights, and a budget overview.

---

Features

Modern UI built with Jetpack Compose
Identity Verification with liveness detection via ML Kit
Budget Allocations with progress tracking and threshold alerts
Transaction Ledger with manual entry, capture and upload options
Spending Trend chart with smooth curved area graph
Spending Velocity bar chart showing daily spend over 7 days
Category management with live budget tracking

---

Tech Stack

Language: Kotlin
Framework: Android Jetpack Compose
Architecture: Single-Activity, Composable-driven
Tools: Android Studio
Camera: CameraX + ML Kit Face Detection
